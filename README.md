## 🧠 Sobre mim

Sou consultor de crédito de dia, dev de madrugada. Trabalho com contratos consignado, mas cansei de fazer tudo na mão — então escrevo bots e sistemas pra fazer o trabalho chato por mim enquanto eu foco no que realmente importa: fechar contrato.

Fora do código: Valorant, Minecraft, Michael Jackson tocando no fundo e um treino de BJJ pra descontar o estresse do dia.
